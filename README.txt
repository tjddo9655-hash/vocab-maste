단어마스터 v26 — 영단어 자동 발음 / 음성 ON·OFF

설치 및 업데이트
1. ZIP 파일을 압축 해제합니다.
2. GitHub Pages 저장소 루트에 압축 파일 안의 전체 파일을 업로드/덮어쓰기합니다.
3. 변경 사항을 Commit하고 배포가 끝난 뒤 앱을 새로 열어 최종 업데이트 v26을 확인합니다.
4. iPhone에서 구버전이 남아 있다면 웹앱을 완전히 종료한 뒤 다시 열어 주세요.

발음 기능
- 기본값: 자동 발음 켜짐.
- 홈 화면(학습 지표 아래) 또는 시험 설정에서 자동 발음 ON/OFF.
- 영어→한글 선택/입력: 새 문제에 영어 단어가 표시되면 자동 재생.
- 한글→영어 입력: 답안을 제출한 뒤에만 정답 단어를 자동 재생(정답 유출 방지).
- 문제와 단어장에 추가한 🔊 발음 듣기 버튼을 누르면 수동 재생.
- 음성은 기기 브라우저의 Web Speech API로 생성하며 기본 언어는 영어(미국)입니다.
- OFF인 상태에서도 사용자가 🔊 버튼을 누르면 발음을 수동으로 들을 수 있습니다.
- iOS Safari는 처음 재생할 때 화면 터치가 필요할 수 있고, 음성 품질이나 오프라인 재생 여부는 설치된 기기 음성에 따라 다릅니다.
- '정답·오답 효과음'은 자동 발음 설정과 별개의 기존 기능으로 유지됩니다.

데이터 및 제한
- 기존 학습 기록은 이전 버전과 같은 저장 키에 유지됩니다. 배포 전 '기록'에서 백업을 권장합니다.
- 자동 발음 설정은 브라우저 로컬 저장소에 별도로 기록됩니다.
- 2,000개 발음을 개별 녹음한 파일이 아니라 기기 자동 음성 합성입니다.
- 표제어 중 문맥에 따라 발음이 달라지는 단어의 특정 발음을 사전 검증한 녹음은 제공하지 않습니다.
- 완전한 오프라인 음성 재생은 운영체제에 설치된 영어 음성에 따라 달라질 수 있습니다.
- 전체 동의어/품사 사전 전수 검증은 완료되지 않았습니다.
