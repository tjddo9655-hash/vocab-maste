단어마스터 - 워드마스터 수능 2000 시험지 기반 PWA

DAY 1~50 / 2,000개 영어 표제어와 한국어 대표 뜻을 포함합니다.
PDF에는 영어만 있고 한국어 뜻은 빈칸이므로, 한국어 뜻은 일반적인 사전 의미를 참고하여 별도로 작성한 것으로 출판사의 공식 표기와 다를 수 있습니다.
뜻의 문맥별 차이 및 자동 채점의 오판정 가능성이 있으므로 정답 수동 인정 기능을 제공합니다.

아이폰 설치: HTTPS 정적 호스팅에 이 폴더의 파일 전체 업로드 → 아이폰 Safari에서 접속 → 공유 → 홈 화면에 추가.
ZIP 압축 해제만으로는 PWA를 홈 화면에 설치할 수 없습니다.
학습 기록은 해당 브라우저에 저장되며 통계 화면에서 백업할 수 있습니다.

품사: 2,000개 모두 지정. 자동 분류로 일부 복수 품사/동음이의어 오분류 가능, 사전 전수 대조는 미완료.
GitHub Pages: ZIP 압축 해제 후 vocab-master-pos 폴더 내부의 파일들을 저장소 최상위에 업로드. Settings > Pages > Deploy from a branch > main / (root).

변경 사항: 홈 학습 방법/아이폰 설치 안내 및 단어장 CSV 가져오기/내보내기 화면 제거. 오답노트 탭 및 누적 오답 재시험 추가.
